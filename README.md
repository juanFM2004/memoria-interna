# MemoryLab — Memoria Interna

Portal académico interactivo sobre RAM, DRAM, SRAM, DDR5 y LPDDR5X.

## Requisitos
- Node.js 18+ recomendado
- Visual Studio Code

## Ejecutar
```bash
npm install
npm run dev
```

Abre la URL local que muestre Vite, normalmente http://localhost:5173/

## Producción
```bash
npm run build
npm run preview
```

El modelo de RAM se genera directamente con React Three Fiber/Three.js, por lo que no necesitas descargar un archivo GLB para verlo.
